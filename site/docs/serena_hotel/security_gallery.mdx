# Security Photo Gallery

Every photo on this page is freely licensed, and each is credited under its image. The first group was taken **during the April 2026 talks**. The second group shows the **same forces and the same streets on other occasions**, so readers can see what guards the Red Zone. Each caption says which group a photo belongs to. News-agency photos of the 2026 cordon itself are copyrighted and are linked on [News Coverage](./news_coverage).
