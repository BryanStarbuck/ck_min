              pdftotext / OCR sidecars, plus the hearing transcripts
  Work files  site/docs/court/legal_docs/_work/
              docket data, fetch logs, per-lane discovery notes

A PDF placed under site/docs/ is NOT served and 404s for every real
visitor. That is why the PDFs live under site/internals/static/ and only
the text lives under docs/. The _markdown/, _text/ and _work/ directories
begin with an underscore, so Docusaurus excludes them from the built site.

THE DIGITAL SIGNATURES ARE REAL AND WERE PRESERVED
  17 of the court's signed orders are image-only PDFs carrying digital
  signatures. ocrmypdf refuses to touch a signed PDF because OCR would
  invalidate the signature. Those files were OCR'd to a SIDECAR TEXT FILE ONLY,
  writing the modified PDF to a temp path that was discarded - so every original
  PDF in this archive still carries its intact signature. Do not run any tool
  that rewrites those PDFs in place.

MARKDOWN CONVERSION
  Pandoc CANNOT do this job - pandoc has no PDF reader, it can only write PDF.
  The conversion uses pymupdf4llm (_work/pdf_to_markdown.py), which reads the
  PDF's own text and layout objects and emits real pipe tables where it detects
  a table. That matters here because the exhibit lists, witness lists and
  restitution notices are column data that a naive text dump destroys. For
  image-only filings it falls through to Tesseract OCR. Expect ordinary OCR
  artifacts in the scanned orders ("Attomey" for "Attorney"). THE PDF IS THE
  RECORD - where the Markdown and the PDF differ, the PDF governs.

WHAT WAS DELIBERATELY NOT DONE
  * No paywall, login, or CAPTCHA was bypassed. Routes that require payment or
    a human are listed above rather than circumvented.
  * No claim of suppression is made anywhere from a failed fetch. Every
    apparent removal was tested against a control: the Utah County Attorney CMS
    503 and the Wayback playback 503 both failed identically for unrelated
    control URLs, so both are outages, not takedowns.
  * AI-generated commentary was moved OUT of the primary-source directories
    into analysis/ so it can never be mistaken for a filing.
