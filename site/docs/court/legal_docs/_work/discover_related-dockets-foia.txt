Utah law on when a warrant becomes public:
  URCRP Rule 40  https://legacy.utcourts.gov/rules/view.php?type=urcrp&rule=40  HTTP 200
    Warrant + application + all affidavits/recorded testimony are PUBLIC once
    unsealed. Warrant materials stay sealed 20 days after issuance unless that
    period is extended or shortened.
  Utah Code 77-23-205: serve within 10 days; return to the court within 3 days.
  Utah Code 77-23-206: sealing on a showing of good cause.
  Utah Code Title 77 ch.23 pt.2 (PDF, HTTP 200):
    https://le.utah.gov/xcode/Title77/Chapter23/C77-23-P2_1800010118000101.pdf
  UCJA 4-202.02 (which court records are public):
    https://legacy.utcourts.gov/rules/view.php?type=ucja&rule=4-202.02
