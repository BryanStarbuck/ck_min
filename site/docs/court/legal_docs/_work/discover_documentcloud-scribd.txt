# LANE SUMMARY (documentcloud / scribd / public doc-hosting platforms)
################################################################################
The lane's own headline platforms were mostly walls: DocumentCloud is Cloudflare-blocked to
curl (but reachable via WebFetch), Scribd is behind a Fastly JS challenge, Trellis/Justia are
Cloudflare-blocked, UniCourt has no free search at the path tried, and CourtListener/RECAP has
literally nothing because this is a Utah STATE case.

What the lane DID produce, in order of value:
 1. andreaburkhart.substack.com -- 258 free direct-download PDFs across a 720-entry docket
    reconstruction current to 8-31-26, PLUS a separate page of 25 search-warrant affidavits.
    This single source covers essentially the entire May-2026-through-August-2026 gap,
    including all three bind-over briefs. Verified 14 PDFs at HTTP 200 / application/pdf.
 2. rev.com -- all five days of the preliminary-hearing transcript, free, HTTP 200.
 3. DocumentCloud project 224251 -- 46 filings whose TITLES CARRY DOCKET NUMBERS, which the
    local inventory lacks; useful as a docket-number crosswalk even for PDFs we already hold.

    body-worn camera footage of the 9/11/25 arrest.
