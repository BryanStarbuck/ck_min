# Sources

The master source list for this site. Individual notes cite the specific sources they rely on; this page collects them. **The standard is primary sources first** — court documents, official agency statements, and sworn testimony — with mainstream reporting as secondary support. This resource **does not rest conclusions on advocacy groups or dedicated fact-check outlets** (see [[About This Project]]).
