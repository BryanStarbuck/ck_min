# Public Safety Assessment

**Filed by:** Pretrial services (intake) — automated risk-assessment report, no individual affiant named · **Date:** 2025-09-12 · **Type:** assessment

## What it is
A standardized pretrial risk-assessment report generated at Robinson's booking to inform the court's release-versus-detention decision on the aggravated-murder, felony-discharge, and obstruction charges.

## What it argues / establishes
The report scores two actuarial scales — New Criminal Activity and Failure to Appear — from a fixed set of risk factors. It records Robinson's age at arrest (listed as 22), notes the current offense is a violent one, and finds no pending charge, no prior misdemeanor or felony conviction, no prior violent offense, no prior failures to appear, and no prior incarceration. It marks "Elevated Risk of Committing Violent Crime: No." Despite the largely clean history, because the top charge is a capital/PRL5 offense, the tool's recommendation is to **detain if the defendant qualifies under Utah Code 77-20-201**, or otherwise release only on maximum conditions and/or monetary bail. The report lays out the graduated pretrial-release condition levels (ROR through PRL5) that would apply if release were granted.
