# State Response to Second Supplemental Discovery Request

**Filed by:** Utah County Attorney's Office (Gray, Grunander, McBride, Hunt, Sturgill, Ballard) · **Date:** 2026-07-02 · **Type:** discovery response

## What it is
The State's response to the defense's **second supplemental request for discovery** (filed June 19, 2026).

## What it argues / orders
Addresses the defense's follow-up discovery demands item by item — what the State will produce, what it objects to, and what it says does not exist.

## The other side
The defense's position is set out in its **June 19** request; the dispute traces back to the defense's **April 3** supplemental request and the State's **April 10** objection.

## Why it matters
Part of the running **discovery dispute** — much of it tied to the defense's pursuit of the prosecutors' media contacts (the publicity/contempt issue). See [[Prosecution Problems]].
